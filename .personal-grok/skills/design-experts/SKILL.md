# 使用设计专家团队

优先把设计任务委派给 `design-expert`；如果任务明确只属于一个领域，也可以直接调用对应的 `design-*` 专家。

- 只加载完成任务所需的专家，避免无关上下文。
- 向专家传递现有产品事实、目标用户、平台、技术限制和期望交付物。
- 要求专家区分事实、判断与假设，并给出可执行的验收标准。
- 最终由主 Agent 汇总成一个一致方案；子专家输出不是最终产品状态的权威。
