## Symptom and root cause

`acp_tool_update` mapped `BashOutput` using timeout and signal fields but ignored
`exit_code`. A normal command with exit code 1, no signal, and no timeout was
therefore emitted as ACP `Completed`.

`BashOutput.exit_code` is a required integer, and Bash Mode plus Streaming
Terminal already map nonzero values to `Failed`. The generic conversion also
feeds tool success/failure signals, so correct raw-output rendering alone does
not repair the protocol state.

## Verification lesson

The first comparison reused one Cargo target across two source trees. Cargo
then reused the old test binary in the real worktree, creating a false failure.
A later successful command also masked that failure because the ad-hoc chain
did not stop immediately. Repository rules now require isolated targets and
fail-fast command chains.
